# BB 课件批量下载 · v2.8.3

在 CUHK / CUHKSZ 的 Blackboard Original 课程内容页中，一次扫描当前入口可达的文件夹，勾选课件后按原目录结构保存。适用于地址中含 `listContent.jsp` 的课程页面。下载使用当前浏览器已有的访问权限。Blackboard Ultra 页面暂不支持。

**有反馈想找我？** 写信到 **ibashgnay@gmail.com**。附上截图、控制台里以 `[bbdl]` 开头的日志、以及你当时点了几次什么按钮，定位最快。提需求也欢迎，不过我更想先听你描述场景——你希望它替你省下哪一步。

## 安装

以下以 Chrome 为例。使用 Chrome 时，在 Tampermonkey 官网切换到 Chrome，再进入对应的扩展商店。**已经装好 Tampermonkey 的用户可以从第 2 步开始。**

1. **安装扩展。** 打开 [Tampermonkey 中文官网](https://www.tampermonkey.net/index.php?browser=chrome&locale=zh_CN)，选择正式版（不要测试版）进入浏览器扩展商店——官网上的入口名称和位置会变，认准正式版即可。在商店点击「添加至 Chrome」（Edge 为「获取」），按浏览器提示确认。
2. **允许扩展运行用户脚本。** 在 Chrome 的扩展管理页找到 Tampermonkey，进入「详情」，确认扩展已启用。若浏览器要求先「允许用户脚本」才肯执行，请在该扩展的「详情」里打开对应开关。不同浏览器与版本的入口不一样，以 Tampermonkey 官方说明为准：[允许用户脚本的权限说明与截图](https://www.tampermonkey.net/faq.php?locale=zh_CN&q=Q209)。
3. **安装下载脚本。** 在刚才安装扩展的同一浏览器中点击 [安装 BB 课件批量下载](https://raw.githubusercontent.com/berserkross/bb-bulk-course-downloader/main/bb-bulk-course-downloader.user.js)。Tampermonkey 会显示安装确认页。核对名称「BB 课件批量下载」和版本后点击「安装」。打开 Tampermonkey 管理面板，在「已安装脚本」中确认它已启用。
4. **验证。** 登录学校 Blackboard，打开课程内的「课程内容 / Course Content」文件列表页并刷新。**左下角**出现「BB 批量下载」面板或折叠小条即表示安装成功。点击小条可展开面板。

**点击安装链接却只看到代码？** 先检查扩展是否装在当前浏览器配置文件中、是否已启用，然后重新打开第 3 步的链接。也可在 Tampermonkey 管理面板的「实用工具」里通过 URL 导入该链接。**课程页面没有面板？** 请确认地址含 `listContent.jsp`、扩展有权访问该学校站点，并在启用权限或脚本后刷新课程页。若曾安装过现场取证版，请仅启用正式脚本。

**更新。** 正式版的更新地址指向本仓库 main 分支的根目录脚本。可等待 Tampermonkey 定期检查，或在管理面板主动检查更新；更新后刷新已打开的课程页。

## 第一次下载

1. 在课程内容页展开面板，点击「开始扫描」。扫描范围取决于当前入口及账号权限；希望覆盖更多目录时，请从课程顶层内容页开始。
2. 点击「选择并下载」，按文件名搜索、按扩展名筛选或手动勾选。体积未知时可使用「获取体积」。默认保留原始目录结构。
3. 在支持目录写入的浏览器中点击「选择保存位置」，选择这门课程的专用文件夹并授权。核对底部的已选数和将跳过的文件数，再点击「开始下载」。下载期间保持标签页打开。
4. 下次更新同一课程时选择同一个目录，使用「只下载新增与变更」。例如选中 156 项、提示其中 154 项会跳过，本次实际待下载的是 2 项。跳过依据包括清单及可获得的磁盘信息，不代表逐字节验证了本地副本。

## 保存方式与限制

| 保存方式 | 使用时机 | 文件组织与资源占用 |
| --- | --- | --- |
| 写入文件夹 | 浏览器支持目录选择且已授权 | 按块写入。可保留目录树；浏览器可能要求重新授权。 |
| ZIP | 无目录写入权限时的默认方式 | 串行读取，包内可保留层级。默认以 200 MiB 为分包目标，且只在文件边界切分——遇到单个大文件时该包会大于目标值。使用 STORE 格式，封包期间需占用与包体积相当的内存；不支持 ZIP64，单文件上限 4 GiB。 |
| 逐文件下载 | 选择逐文件降级方式时 | 交给浏览器下载，目录信息可编码到文件名前缀；单个文件需暂存在内存中。 |

- **命名与 HTML 课件。** 优先使用响应头提供的名字，其次使用符合条件的最终 URL 文件名或页面标题。v2.8.3 支持可识别的 HTML 课件，包括内嵌脚本的 Pandoc 文档。判据是保守的：文件名以 `.html` / `.htm` 结尾，且能由响应头、最终 URL 或页面标题之一确认身份；没有标题、又拿不到文件名的 HTML 无法确认，仍按异常响应处理。服务器返回登录表单、拦截页时同样会暂停或失败。
- **续跑与异常响应。** 完成状态按文件记录：暂停后续跑、只重试失败项或自动恢复时，面板显示的是同一批次的累计结果；重载后的续跑要求仍能读取已保存的目录句柄及其权限，等待期间进度可能停在原地，最终暂停时会列出未下载数量。下载途中若持续收到可疑页面，会自动降速乃至暂停；ZIP 包里只成功取得部分文件时，会交付已封好的部分并允许重试缺项，但已经开始、没写完的单个文件必须从头再来。
- **扫描范围。** 只沿地址含 `listContent.jsp` 的入口展开子文件夹。若某部分目录由其它页面类型承载，那部分不会被扫描到，也不会单独提示；需要更完整的覆盖时，请从课程顶层内容页进入。
- **增量判断。** 使用文件标识、版本链接、路径、已知大小及完成状态进行比较。在没有内容哈希的情况下，链接和大小均未变化的内容替换可能无法识别。疑似删除只提示，不会删除本地文件。支持导出、导入清单和查看最近扫描历史。
- **显示范围。** 面板文件列表最多渲染 500 行；该上限不限制扫描或下载的文件数。

## 隐私与权限

- 只请求你自己有权限查看的课程文件，不绕过登录、不猜测地址。
- 课程内容与账号信息不会发往任何第三方；清单、设置与目录句柄只存在本机的 IndexedDB / localStorage。
- 代码不做混淆；除 Blackboard 站点本身与脚本更新地址外，没有其它外部请求。

## 开发与发布

源码在 `src/`，自动化测试在 `tests/`。使用项目锁文件安装开发依赖，先构建再测试，使集成测试能够加载实际分发的脚本。

```sh
npm ci
npm run build
npm test
```

CI 会跑同样的构建与测试，并额外执行两件事：`node scripts/check-docs.mjs`（README 的版本、测试数、路径与命令必须与仓库一致）和产物一致性检查（重建后仓库根脚本的 `git diff` 必须为空）。

v2.8.3 发布检查共 500 项测试。构建生成 `dist/bb-bulk-course-downloader.user.js`，并复制到根目录。根目录副本供安装及自动更新使用。发布时应同时提交源码、版本号和重建的根目录脚本，核对公开安装链接的版本与 SHA-256。

设计取舍与不变量写在 `docs/` 下 9 份契约文档里；改行为先改文档，再改实现与测试。仓库根目录那份产物约 295 KB、`src/` 约 9700 行——GitHub 的语言统计会把打包产物判为 generated 而排除，页面上显示的体量不代表实际规模。

## 项目来源

本仓库 fork 自 [JesperroO/bb-bulk-course-downloader](https://github.com/JesperroO/bb-bulk-course-downloader)。原作者那份单文件脚本（`blackboard-download.user.js`，v2.1）至今仍在原仓库的 [core 分支](https://github.com/JesperroO/bb-bulk-course-downloader/tree/core) 上，也是这件事真正的起点：递归扫描子文件夹、用服务器响应里的真实文件名而不是 `xid-XXXX` 占位名、小并发加重试——这三条思路都由它先跑通。

fork 之后，`main` 分支逐步换成了模块化实现：目录树落盘、断点续传与增量判断、逐文件事件、ZIP 降级、会话异常自愈。安装方式与「只访问你有权限的文件」这条底线没有变。感谢 JesperroO 把这套思路和原始脚本公开出来。
